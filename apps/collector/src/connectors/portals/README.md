# Portais homologados

Nenhum portal adicional está habilitado. Novos conectores implementam SourceConnector e usam origens fixas revisadas. Crawlee/Cheerio e Playwright estão disponíveis; instanciar apenas após homologação, inspeção de DNS/endereços e política de acesso. Sugestões de usuários são dados para análise humana, nunca entradas do crawler.
